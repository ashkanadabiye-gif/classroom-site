# سامانه کلاس مجازی — نسخه یکپارچه ارتقایافته

این بسته شامل سورس کامل پروژه Django، رابط بازطراحی‌شده کلاس، امکانات مدیریت جلسه، ضبط کلاس و چت خصوصی ذخیره‌شونده است.

## امکانات موجود در این نسخه

- ثبت‌نام و ورود استاد و ساخت کلاس با لینک اختصاصی
- تعریف دانش‌آموزان توسط استاد و ورود دانش‌آموز با نام، نام کاربری و رمز
- امکان غیرفعال‌کردن ورود مهمان
- کلاس زنده صوتی/تصویری مبتنی بر WebRTC، اشتراک صفحه و کنترل میکروفون/دوربین
- چت عمومی با ذخیره در پایگاه داده
- **چت خصوصی یک‌به‌یک بین استاد و دانش‌آموز**؛ دانش‌آموز فقط می‌تواند به استاد پیام بدهد، پیام‌ها ذخیره می‌شوند و دانش‌آموز به پیام‌های دیگران دسترسی ندارد
- تخته سفید همگام با ابزارهای ترسیم، چند صفحه در نشست، Undo/Redo و نشانگر لیزری
- نظرسنجی و آزمون سریع با نتیجه زنده
- بارگذاری فایل توسط استاد و دانلود کنترل‌شده برای افراد همان کلاس
- ضبط جلسه از مرورگر استاد و ذخیره/دانلود فایل ضبط‌شده
- حضور و غیاب، گزارش مدت حضور و خروجی CSV
- دست بالا بردن، تغییر نام مهمان، کنترل دسترسی‌ها و اخراج موقت
- سنجش تقریبی وضعیت شبکه در مرورگر

## نصب در ویندوز

در CMD یا PowerShell، وارد پوشه‌ای شوید که `manage.py` داخل آن است:

```powershell
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py manage.py migrate
py manage.py createsuperuser
py manage.py check
py manage.py runserver
```

سپس `http://127.0.0.1:8000` را باز کنید. استاد ثبت‌نام می‌کند، وارد داشبورد می‌شود و کلاس می‌سازد.

## اجرای سریع در لینوکس

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py check
python manage.py runserver
```

## تنظیمات محیطی

نمونه متغیرها در `.env.example` آمده است. برای محیط عمومی حتماً `DJANGO_DEBUG=0`، یک `DJANGO_SECRET_KEY` تصادفی و `DJANGO_ALLOWED_HOSTS` دقیق تنظیم کنید و سایت را فقط با HTTPS منتشر کنید. برای Channels در چند پردازه، Redis را فعال کنید و `REDIS_URL` بدهید. تنظیمات TURN نیز برای اتصال پایدار WebRTC پشت NAT/فایروال لازم است.

## داده‌ها و فایل‌ها

فایل `db.sqlite3` عمداً داخل بسته قرار نگرفته است تا اطلاعات حساب‌ها یا داده‌های محیط آزمایشی منتشر نشود. با اجرای `migrate` دیتابیس جدید ساخته می‌شود. فایل‌های آپلود و ضبط در `media/` ذخیره می‌شوند؛ از این پوشه و دیتابیس به‌صورت منظم نسخه پشتیبان بگیرید. در هاست‌هایی با فایل‌سیستم موقت، فایل‌های آپلودشده ممکن است بعد از restart یا deploy از بین بروند.

## محدودیت مهم ظرفیت کلاس

**این نسخه هنوز از WebRTC به روش Mesh استفاده می‌کند و برای ۵۰ دانش‌آموز هم‌زمان آماده یا آزمون‌شده نیست.** در Mesh هر شرکت‌کننده به چندین شرکت‌کننده دیگر اتصال رسانه‌ای برقرار می‌کند و بار شبکه/پردازنده به‌سرعت بالا می‌رود. امکانات چت، تخته، حضور و غیاب و مدیریت جلسه را می‌توان نگه داشت، اما برای هدف ۵۰ دانش‌آموز باید مسیر صوت/تصویر به SFU مانند LiveKit منتقل و روی سرور دارای پهنای باند و پورت‌های UDP مناسب مستقر شود. صرفاً رایگان بودن کد یا نصب Redis این محدودیت را حل نمی‌کند.

## بررسی قبل از انتشار

پس از نصب، `py manage.py check` و `py manage.py migrate --check` را اجرا کنید. سپس ورود استاد/دانش‌آموز، چت عمومی، چت خصوصی بین چند حساب، مجوزهای میکروفون/دوربین، بارگذاری/دانلود فایل، ضبط، حضور و غیاب و قطع اتصال را در مرورگرهای جداگانه آزمایش کنید. تا پیش از آزمون بار واقعی، ظرفیت ۵۰ نفر را به کاربران وعده ندهید.
